My work spans systems experiments, backend services, data-heavy platforms, real-time interfaces, developer tooling, AI-assisted workflows, and production UI packages. I like software that has teeth: fast, inspectable, practical, and built for technical users who need the system to actually work.

## RiskLab packages

RiskLab is my public frontend systems lab: polished TypeScript packages for analytical interfaces.

- [`risklab-ui`](https://github.com/devgrrl/risklab-ui): UI primitives and React/framework adapters.
- [`risklab-charts`](https://github.com/devgrrl/risklab-charts): chart engine, themes, adapters, and 2D/3D visualization surfaces.
- [`risklab-styler`](https://github.com/devgrrl/risklab-styler): typed deterministic styling primitives.
- [`risklab-icons`](https://github.com/devgrrl/risklab-icons): original SVG icon system for technical tools.

The point is simple: I can build deep systems, backend services, data workflows, and polished user-facing tools — and I can ship them cleanly.
