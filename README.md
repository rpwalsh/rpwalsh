# RiskLab

RiskLab is a free, production-focused TypeScript toolkit for building data-intensive interfaces: [UI](https://github.com/devgrrl/risklab-ui), [Charts](https://github.com/devgrrl/risklab-charts), [Icons](https://github.com/devgrrl/risklab-icons), and [Styler](https://github.com/devgrrl/risklab-styler). Together they provide accessible application components, interactive 2D and 3D visualization, an original SVG icon catalog, and deterministic typed styling with framework adapters where useful.

Each package is independently versioned, browser-tested, validated through installed-tarball consumer fixtures, and licensed under Apache-2.0. Releases install from the `@risklab` npm scope, while the linked repositories contain source, documentation, examples, and contribution guidance.
